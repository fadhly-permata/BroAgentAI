# BroAgentAI v0.2.0

**Release date:** 2026-11-23

Local release notes for BroAgentAI (**Bro**wser **Agent** **AI**). This version adds installers, a checksum-verified updater, and release tooling. GitHub publishing is intentionally not performed here because the account has a pending payment lock.

The full list is in [CHANGELOG.md](../../CHANGELOG.md#020---2026-11-23).

## Highlights

- GUI installers: a WinForms wizard on Windows, zenity/osascript dialogs on macOS/Linux, and CLI fallbacks via `install.ps1` / `install.sh`.
- Firefox is covered by the native host installers alongside Chrome, Chromium, Edge and Brave.
- `npm run update:check` reports the newest release; `npm run update` verifies `SHA256SUMS.txt`, safely extracts the ZIP, backs up the current install, rolls back on failure and re-registers the native host.
- Settings shows the installed host version and opens update instructions when it differs from the extension version.
- Fixed a false **Host ready** state when the native host port closed before the `system.ping` handshake finished.

## Downloads

These files are built locally with `npm run release` and land in `release/`:

| File | What it is |
| --- | --- |
| `broagentai-v0.2.0-<os>-<arch>.zip` | Ready-to-run bundle: built extension, built bridge, runtime dependencies, installers and these notes. No `npm install` or build needed. |
| `broagentai-v0.2.0-source.zip` | Source code at this version. |
| `SHA256SUMS.txt` | Checksums for both zips. |

The bundle includes `node-pty`, which is a native module, so a bundle only works on the OS and CPU it was built on (for example `win32-x64`). On anything else, use the source zip or a clone.

## Install

See [docs/installer.md](../installer.md) for GUI, CLI, per-browser and uninstall instructions.

Quick start from a bundle:

```powershell
Expand-Archive .\broagentai-v0.2.0-win32-x64.zip
.\broagentai-v0.2.0-win32-x64\install-gui.ps1
```

```bash
unzip broagentai-v0.2.0-linux-x64.zip
cd broagentai-v0.2.0-linux-x64
./install-gui.sh
```

## Update

```bash
npm run update:check
npm run update
```

Pass `--yes` to `scripts/update.mjs` only when the checksum and target version have been reviewed.

## Verify the download

```powershell
Get-FileHash .\broagentai-v0.2.0-win32-x64.zip -Algorithm SHA256
```

```bash
sha256sum -c SHA256SUMS.txt
```

## Known issues

- GitHub Actions is blocked by an account billing lock; CI and the release matrix have not run remotely.
- macOS and Linux bundles in this local `release/` directory are not built; only the current platform bundle is generated locally.
- Signed/notarized distributables remain pending credentials. The release workflow has an optional signing hook but no signing material.
- Manual clean-profile sign-off on Windows, macOS, Linux and Firefox has not been performed.
- GitHub publishing is manual and user-only until billing is resolved.
